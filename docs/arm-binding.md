# 手臂联动

手势 `gesture` 中的 accents 默认使用 `armBinding: "guided"`；`"off"` 保留旧版独立关节值，供对照和手工调参。没有 accents 的原生动作完全不变。当前只处理抚胸、竖食指、拿草的关节变化片段，不改写 recorded 数据。

每种手势从作者进入动作末帧取得大臂、小臂、手腕、透视基准。竖食指的小臂基准约 0.702，拿草约 -0.732，因此不能使用统一的绝对角度区间。算法相对基准联动：大臂带动小臂，小臂调整给大臂少量补偿，手腕做有限反向补偿；同时限制关节偏移和透视变化。片段共享 45 Hz 时间点，并保留边界淡入淡出、作者进入/收回、手势开关。

这是本模型的保守二维参数约束，不是骨骼 IK，也不保证手掌精确到达某个目标点。系数在 arm_binding.py 中，后续可按三种手势分别校准。修正结果写入编译轨道，因此网页、离线导出与 VTS 部署消费同一结果；本轮实测的是网页。

验证：15 个现有预设重新编译成功，10 个含修正提示；83 项 Python 检查及 Node 检查通过。网页同姿势对照中，小臂输入从 -0.55 修正至约 0.2133，大臂 -0.15 → -0.3754，手腕 0.5 → 0.38；截图确认原内折姿态变为向外展开。尚未逐个预设完成视觉验收。
