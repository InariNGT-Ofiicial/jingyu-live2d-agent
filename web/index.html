MODEL NOTES
从模型结构，到自然动作
作者模型包含 509 个参数、147 个部件、715 个画元，配有 131 组物理、8 份动作和 23 份表情。
先驱动输入，再让物理接力
头部使用 AngleX / Y / Z，身体使用 PositionX / Y / Z。它们经过作者的物理链，传到实际变形参数。头发、衣饰、眼部与尾巴随之响应。
动作由小片段组成
注视、点头、摇头、歪头、微笑、眨眼、原生表情与手势可以按时间组合。每个片段有进入、停留与退出；结束后回到自然待机。
保留作者的手势过渡
抚胸、竖食指、狗尾草使用原生 motion3 动画，并成对播放进入和收回。手势切换不靠凭空摆动图层。
选择你的语义编排来源
可使用本机 DSH、OpenAI 兼容 API，或通过指令箱交给当前 Codex。编译器负责范围检查、通道冲突与时间约束，再等待舞台执行回执。
能力范围
支持模型已有的头眼、细面部控制、大幅头身联动与原生手势；连续轨迹可在中间姿态间直接过渡。自由走路、跑步和背面转身不在模型能力内。说话动作仅驱动口型，不生成音频。
原画及拆分：神宫凉子 · Live2D 建模：霓虹猫_NeonNeko
