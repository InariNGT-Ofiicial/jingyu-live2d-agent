## 幅度与速率

实际头部输出 ParamAngleX：A 约 -20.25..21.07，B 约 -15.80..16.24，C 约 -21.14..20.19。快速转向关键帧跨度约 0.45–0.55 秒；A 头部输入峰值采样变化率约 102 参数单位/秒。这里是模型参数数值，不是由画面测出的物理角速度。

左右重心驱动 HipAngleX，再联动 LEGAngleZ2 与 Param33，三组实际腿部输出均有变化。尾部实际 ID 为 Param_Angle_Rotation84/87，三组摆动跨度约 5–16 参数单位；不能用不存在的 Rotation84/87 简写当作零输出证据。

表情与身体在同一时间轴执行；脸红可持续跨越多次转向，眨眼与微笑未发生编译冲突。采样无非有限值。结束 1.2 秒后 key7、Param62/60/36/41 均回到 0。A/B 手臂引导约束产生预期提示，不是播放错误。

手势进入仍保留作者 1.13–1.25 秒、退出 1.02–1.25 秒；头部转向明显比手型切换快。这是当前手势编译的明确节奏限制，未为追求速度裁掉作者切换帧。
